# Project Brief: Olist Delivery Analysis

## Main question
Are late deliveries hurting customer satisfaction, where is the problem concentrated, and what would fixing it be worth?

## Sub-questions
1. Do late orders get lower review scores than on-time orders, and by how much?
2. Which states have the highest late-delivery rates?
3. Which sellers have the highest late-delivery rates?
4. Is the late-delivery rate improving or getting worse over time?

## Audience
Operations manager of an e-commerce marketplace.

## Data source
Brazilian E-Commerce Public Dataset by Olist, via Kaggle.
Link: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
